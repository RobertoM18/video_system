# Requerimientos

**NodeJS**: https://nodejs.org/en/download.  
**Larvel 12**: https://laravel.com/docs/12.x/installation.  

# Como ejecutar el proyecto

En una terminal ejecutar lo siguiente:

`git clone -b sqlite https://github.com/RobertoM18/video_system.git`  

`cd video_system`  

`composer install`

`npm install && npm run build`

`php artisan migrate --force && php artisan db:seed`

`composer run dev`

Ingresar luego en navegador ingresar a [localhost:8000](http://localhost:8000)
